# EBX Nexus

Create a premium, modern, and highly interactive web-based game store inspired by high-end creative studio experiences like unseen.co projects.



====================================

1. UI / UX DESIGN

====================================

- Dark ultra-modern gaming theme (black + neon purple/blue gradients)

- Glassmorphism + soft shadows

- Clean, minimal, premium layout

- Large bold typography (gaming style)

- Fully responsive (mobile-first design)



====================================

2. HOMEPAGE

====================================

- Hero section:

  Title: "EBX Game Store"

  Subtitle: "Top Up & Play Instantly"



- Add search bar

- Add category filters:

  Shooter / Sports / Sandbox



- Games grid (animated cards):

  - PUBG Mobile

  - Free Fire

  - Call of Duty Mobile

  - Fortnite

  - eFootball 2024

  - Roblox



====================================

3. GAME CARDS (HIGH-END DESIGN)

====================================

- Each card includes:

  - Game image/logo

  - Animated gradient background

  - Glow border on hover

- Animations:

  - Hover (desktop): scale + 3D tilt + glow

  - Tap (mobile): smooth press animation



====================================

4. GAME PAGE (APP-LIKE EXPERIENCE)

====================================

- Full screen (like opening an app)

- Smooth zoom-in transition

- Sticky header with game name

- Back button / swipe back

6. PLAYER ID SYSTEM (MANUAL)

====================================

====================================

- Input field: "Enter Promo Code"

- Real-time price update

- Invalid → show error message

====================================

- On "Buy Now":
